# 目的別口座監理アプリ (PRE-FUND SIMULATOR)

このアプリは、将来の支出（車検、旅行、家電の買い替えなど）に向けて、どの口座でいくら積み立てる必要があるかをシミュレーションし、管理するためのアプリケーションです。

## 特徴

- **将来予測シミュレーション**: 36ヶ月（3年）先までの残高推移を可視化。
- **目的別積立**: 各口座内で「目的」ごとに積立額を設定可能。
- **実残高との同期**: CSV形式（住信SBIネット銀行など）の入出金明細を取り込んで、シミュレーションに反映。
- **Google Drive同期**: データをGoogle Driveに保存し、複数の端末で共有可能。
- **プレミアムなUI**: ダークモード対応のモダンで使いやすいデザイン。

## 技術スタック

- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Storage**: LocalStorage & Google Drive API

## 使い方

1. `npm install` で依存関係をインストールします。
2. `npm run dev` でローカルサーバーを起動します。
3. 口座を追加し、その中に積立の目的（目標金額、使用予定月）を登録します。
4. 毎月の収支はCSVをアップロードすることで実残高を更新できます。

## 開発環境のセットアップ

```bash
# クローン
git clone <your-repository-url>

# ディレクトリへ移動
cd 目的別口座監理アプリ

# インストール
npm install

# 起動
npm run dev
```
