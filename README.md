# 目的別口座監理アプリ (PRE-FUND SIMULATOR)

このアプリは、将来の支出（車検、旅行、家電の買い替えなど）に向けて、どの口座でいくら積み立てる必要があるかをシミュレーションし、管理するためのアプリケーションです。

## 特徴

- **将来予測シミュレーション**: 36ヶ月（3年）先までの残高推移を可視化。
- **目的別積立**: 各口座内で「目的」ごとに積立額を設定可能。
- **実残高との同期**: CSV形式（住信SBIネット銀行など）の入出金明細を取り込んで、シミュレーションに反映。
- **フォルダ保存**: File System Access APIで選択したローカルフォルダに保存。再連携時は既存データを先に読み込み、ファイルは上書きしません。
- **バックアップ復元**: 空・破損した保存データは正常なバックアップから読み込み可能。「バックアップから復元」で確認後に保存先へ戻せます。
- **プレミアムなUI**: ダークモード対応のモダンで使いやすいデザイン。

## 技術スタック

- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Storage**: File System Access API / IndexedDB（フォルダ参照）/ LocalStorage（ブラウザ内の控え）

## 使い方

1. `npm install` で依存関係をインストールします。
2. `npm run dev` でローカルサーバーを起動します。
3. 口座を追加し、その中に積立の目的（目標金額、使用予定月）を登録します。
4. 毎月の収支はCSVをアップロードすることで実残高を更新できます。

## 保存・復元の安全性

- 起動・フォルダ再連携は読み取りを優先し、既存ファイルへ書き込みません。正常な `data.json` を優先し、空・破損なら正常なバックアップを更新日時順で探します。
- 保存や復元の前には `data.snapshot-日時-連番.json` を作成します。保存元が空・破損していても、その内容で正常な `data.backup.json` を置換しません。バックアップは自動削除しません。
- 月別残高 `categoryBalances` も読み込み・保存・復元対象です。
- ブラウザ側のフォルダ権限が失効することは防げません。未連携時は接続済みと表示せず、明示的なフォルダ再連携で再取得します。
- 正常なバックアップがない空・破損フォルダへの自動移行は行いません。別のJSONファイルを選んで復元してください。
- 空データの通常保存・復元は禁止します。本人が削除確認した最後の口座の削除のみ `emptyConfirmed` を付けて保存し、次回も意図した空状態を保持します。削除前の正常データはバックアップに残ります。
- ファイル保存の失敗は画面に表示し、画面だけの成功にしません。フォルダ保存に成功し、ブラウザ内の控えだけ失敗した場合は、保存済みデータを反映して警告を表示します。
- フォルダ権限切れ後の編集は、再連携または復元まで停止します。連携先と異なる非空の画面データは、切り替え前にブラウザ内の控え `prefund_before_reconnect` へ退避します。

## 検証

`npm test` で実サービスに接続しない、メモリ上の架空フォルダによる20件の回帰テストを実行できます。`npm run build` で公開用アプリをビルドできます。

`npm run lint` は元のプロジェクトにESLint設定がないため実行できません。今回も警告を無効化する設定は追加していません。
